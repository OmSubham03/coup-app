One room, one friend

  1. Select Play Tic-Tac-Toe now, create a room, and choose a display name.
  2. Send its five-character code to a friend. They open Tic-Tac-Toe's setup and join with the code. If you enable Public room, another player can find the available seat in room discovery.
  3. Once both seats are filled, the host selects Start Game. The host plays X and the guest plays O.

This is a human-versus-human game, not a solo bot mode. No download or account sign-in is needed. If the same tab has a saved game, the app reconnects to it before opening a new setup.

Nine squares, eight winning lines

The board has three rows and three columns. X always moves first, then X and O alternate. On your turn, place your mark in one empty square. An occupied square cannot be changed, and you cannot move twice in a row.

  • Three matching marks across any row win.
  • Three down any column win.
  • Either corner-to-corner diagonal can win.
  • If all nine squares fill without a winning line, the result is a draw.

The server checks every move and stops the round as soon as a win or draw occurs. Spectators do not get a playing seat or permission to mark the board.

Replay and interruptions

After a completed round, either seated player can return the room to the lobby. The host can then start another round. Seats keep their roles: replay does not automatically swap X and O. If a player leaves an active match, the other player wins by forfeit. A temporary connection interruption can be restored using the same tab's saved session; it is not a promise of indefinite room retention.

Follow a diagonal all the way through

  1. X takes the top-left square.
  2. O takes the top-middle square.
  3. X takes the center. X now threatens the bottom-right square.
  4. O chooses bottom-left instead of blocking.
  5. X takes bottom-right and wins along the top-left-to-bottom-right diagonal.

The key decision was O's fourth move. Before making a new threat, check whether the other player can win immediately. Bottom-right would have blocked the diagonal and kept the game alive.

A simple order for choosing a square

  • Win if you can. Look for a line with two of your marks and one empty square.
  • Block an immediate loss. If you cannot win now, close the opponent's open two-mark line.
  • Look for a fork. A move that creates two separate one-move wins can be harder to defend than a single obvious line.
  • Value the center and corners. The center belongs to four winning lines, corners to three, and edge middles to two. Those counts help, but do not replace checking immediate threats.
  • A draw is a good defense. With perfect play, neither player can force a win. Learn which move kept you safe, not just who took the first turn.
